APP NAME
PO Sorting – ಪಿನ್ ವಿಂಗಡಣೆ

SHORT DESCRIPTION
ಇಂಟರ್ನೆಟ್ ಇಲ್ಲದೆ ಪಿನ್ ವಿಂಗಡಣೆ: ಲೈನ್, ಸ್ಥಾನ, ವಾಯು ಕೋಡ್. ಅಧಿಕೃತ ಆ್ಯಪ್ ಅಲ್ಲ.

FULL DESCRIPTION
PO Sorting ಅಂಚೆ ವಿಂಗಡಣೆ ಸಹಾಯಕರಿಗೆ ಪ್ರತಿ ಅಂಚೆಗೆ ಸರಿಯಾದ ಲೈನ್ / ಚೀಲವನ್ನು ಕ್ಷಣಗಳಲ್ಲಿ ತೋರಿಸುತ್ತದೆ – ಇಂಟರ್ನೆಟ್ ಇಲ್ಲದೆ.

ಪಿನ್ ಟೈಪ್ ಮಾಡಿದರೆ:
• TD / Non-TD ಲೈನ್ ಮತ್ತು ಲೈನ್‌ನಲ್ಲಿ ಕಚೇರಿಯ ಸ್ಥಾನ
• ಗಮ್ಯಸ್ಥಾನದ ವಾಯು ಕೋಡ್
• ಆ ಪಿನ್‌ನ ಎಲ್ಲ ಅಂಚೆ ಕಚೇರಿಗಳು

ವಿಳಾಸ ಸ್ಕ್ಯಾನ್
• ಕ್ಯಾಮೆರಾ ಹಿಡಿದರೆ ಪಿನ್ ಮತ್ತು ಕಚೇರಿ ಹೆಸರು ತಾನೇ ಓದುತ್ತದೆ
• ಕೈಬರಹಕ್ಕೆ ಕ್ಯಾಪ್ಚರ್ ಬಟನ್
• ಕನ್ನಡ, ಹಿಂದಿ, ಇಂಗ್ಲಿಷ್ ವಿಳಾಸಗಳು
• ಪಿನ್ ಮತ್ತು ಕಚೇರಿ ಹೊಂದದಿದ್ದರೆ ಎಚ್ಚರಿಕೆ ಮತ್ತು ಉತ್ತಮ ಆಯ್ಕೆ

ಲೈನ್‌ಗಳು
• ಪ್ರತಿ ಲೈನ್‌ನ ಎಲ್ಲ ಕಚೇರಿ ಮತ್ತು ಪಿನ್‌ಗಳು ಸ್ಥಾನ ಕ್ರಮದಲ್ಲಿ
• ಕಚೇರಿ, ಪಿನ್, ಲೈನ್ ಸೇರಿಸಿ / ಬದಲಿಸಿ / ತೆಗೆದುಹಾಕಿ
• ನಿಮ್ಮ ಯೋಜನೆಯನ್ನು Excel / CSV ಯಿಂದ ಆಮದು ಮಾಡಿ

ಗೌಪ್ಯತೆ: ಇಂಟರ್ನೆಟ್, ಲಾಗಿನ್, ಜಾಹೀರಾತು ಇಲ್ಲ. ಕ್ಯಾಮೆರಾ ಚಿತ್ರಗಳನ್ನು ಉಳಿಸುವುದಿಲ್ಲ.

ಮುಖ್ಯ: PO Sorting ಸ್ವತಂತ್ರ ಸಹಾಯಕ ಸಾಧನ. ಇದು ಅಂಚೆ ಇಲಾಖೆ / ಇಂಡಿಯಾ ಪೋಸ್ಟ್‌ನ ಅಧಿಕೃತ ಆ್ಯಪ್ ಅಲ್ಲ. ಯಾವಾಗಲೂ ನಿಮ್ಮ ಕಚೇರಿಯ ಅಧಿಕೃತ ಸೂಚನೆಗಳನ್ನು ಪಾಲಿಸಿ.
